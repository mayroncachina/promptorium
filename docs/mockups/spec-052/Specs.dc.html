Exportar o relatório do Review em PDF

Criada pelo agente na sessão Planejar o export do Review, hoje às 16:12, com a sua aprovação. É um rascunho: nada roda até você aprovar. Abrir a sessão

Objetivo

Hoje o relatório do gate e "O que a resolução decidiu" só existem na tela do Review. Esta spec gera um PDF com os dois, para anexar ao PR ou mandar para quem não usa o app.

Requisitos

  • R1 · O Review deve oferecer "Exportar PDF" no painel "Pronto para merge?".
  • R2 · O PDF deve trazer os critérios, o último gate e as resoluções de conflito.
  • R3 · O arquivo deve ser salvo em .promptorium/relatorios/.
  • R4 · Capa com o logo do projeto. · aviso do lint
  • R5 · O PDF deve ter no máximo 2 MB.
