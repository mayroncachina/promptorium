Parser stream-json em Dart

Como eu leio a saída stream-json do Claude Code em Dart sem travar a UI? Quero cada evento virando um objeto tipado.
Claude Code · Sonnet 5.5

Use Process.start e trate o stdout como um stream de linhas. Cada linha é um JSON completo, então dá para decodificar e mapear para uma sealed class sem bloquear a thread da UI:

sealed class ClaudeEvent { … }

final events = proc.stdout
    .transform(utf8.decoder)
    .transform(const LineSplitter())
    .map((l) => ClaudeEvent.fromJson(jsonDecode(l)));

Para eventos muito grandes, o decode pode ir para um Isolate. Quer que eu escreva os tipos para system, assistant, user e result?
