# vitrine

Loja de demonstração em Flutter, com API em Dart.

## Comandos
- Testes: `flutter test test/<area>`; a suíte inteira só no CI.
- Antes de commitar: `flutter analyze`.

## Regras
- Textos para o usuário em português do Brasil.
- Nunca use `print`; use o logger de `lib/core/log.dart`.
- Tela nova leva teste de widget.
## Onde está cada coisa
- Telas: `lib/features/`. Banco: `lib/data/db/`.
- Detalhes da arquitetura: `docs/arquitetura.md`.
