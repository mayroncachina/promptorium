"App" é o commit que o próprio app faz numa etapa, como "Commitar o que sobrou". Ele pode juntar edição sua e do agente.
Este projeto não marca os commits dos agentes Os agentes commitam com o seu nome, então o git não separa o que você e eles fizeram. Ligada a marcação, os próximos commits das sessões ganham uma linha que o app lê aqui.
De onde vem esta separação Os commits das sessões do app levam uma linha no fim da mensagem, com o modelo e a etapa: Promptorium-Agente: sonnet · SPEC-042 R2 Sem a linha, o commit é seu. Com "app", foi o próprio Promptorium que commitou numa etapa. A marcação está ligada desde 8 nov. As semanas anteriores aparecem em cinza, como sem marca, e não contam como suas.
