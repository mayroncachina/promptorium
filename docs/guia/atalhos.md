# Atalhos de teclado

Ctrl+/ abre a folha de atalhos dentro do app, com filtro.

## Globais

| Atalho | Ação |
|---|---|
| Ctrl+1 … Ctrl+9 | Início, Projeto, Specs, Quadro, Sessões, Review, Código, Prompt, Ferramentas |
| Ctrl+K | Paleta de comandos |
| Ctrl+N | Nova sessão |
| Ctrl+/ | Folha de atalhos |
| F1 | Sobre |
| Ctrl+\\ | Sessões lado a lado |
| Ctrl+Shift+A / Ctrl+Shift+D | Aprovar / negar a pendência mais antiga |

## Editores

| Atalho | Ação |
|---|---|
| Ctrl+= / Ctrl+- / Ctrl+0 | Zoom do editor da tela (Specs e Código têm zoom próprio) |
| Ctrl+S | Salvar (Specs, Código) |
| Ctrl+F / Ctrl+H | Buscar / substituir (Esc fecha) |
| Ctrl+W | Fechar aba (Código) |
| Ctrl+P | Ir para arquivo (Código) |
| Ctrl+Shift+F | Buscar em todos os arquivos (Código) |

## Composer

| Atalho | Ação |
|---|---|
| Ctrl+Enter | Enviar mensagem (Sessões, Prompt) |
| `@` | Inserir arquivo |
| `/` | Inserir prompt salvo |
| ↑ / ↓, Enter / Tab, Esc | Navegar, escolher e fechar as listas de `@` e `/` |
